# 2026 年 11 月

十一月把矢量作业收成一份 Graph。人可以在逐步列表里编辑一条单路径，也可以在画布上编辑分支；两边读写同一份文档，执行仍走现有的 Operator。

## 交付

1. **一份文档。** `#wf=` 解码为 Graph。旧的逐步列表在读入时折成一条单路径 Graph。导出只有 Graph 这一种文件。打开一条单路径链接时，逐步列表和画布看到同一条路径。带分支的 Graph 在逐步列表里进入画布，分支保留。

2. **Second input 可以分享。** 带第二条边的 Graph 能放进链接。链接放不下时下载 Graph 文件。验收：buffer 再 intersect 另一层，复制链接，在新的浏览器里打开并跑完，得到一份 Layer。

3. **缺参数的 Operator 在跑之前就站不住。** `data.fieldCalc`、`data.attributeJoin`、`spatial.moransI` 必须填齐 `runOperator` 要求的参数，节点上直接标出缺什么。`spatial.h3Bin`、`spatial.smooth`、`spatial.concaveHull`、`spatial.spatialJoin`、`spatial.selectByLocation` 的现有默认值可以在节点上改。免费档把 Operator 节点数算进现有的 5 步上限。

## 边界

十一月的范围停在矢量 Graph。栅格、点云、三维、高光谱、SQL 仍是各自的 Tool。`spatial.reproject` 继续只接受 `EPSG:` 编号；GCJ-02 与 BD-09 留在坐标 Tool。`format.convert`、`format.parse`、`format.write`、`data.split` 不进入画布面板：文件从 Source 进入，多份结果不是一条边能接住的。
